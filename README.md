# Yuxin Li's Academic Homepage

Source code for [grit1021.github.io](https://grit1021.github.io/), my personal academic homepage and research portfolio.

I am a PhD student in Applied Mathematics and Computational Science at the University of Pennsylvania. My research focuses on large language models, agentic systems, biomedical AI, scalable deep learning, and trustworthy machine learning.

## Homepage contents

- Education and research experience
- Selected publications and projects
- Research interests and technical background
- Current resume and professional links

## Local development

This site is built with Jekyll and deployed through GitHub Pages.

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000`.
